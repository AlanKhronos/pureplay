## 一、最紧急：今天就能做的四件事

### ① 定下游戏名称（**最优先**，因为它不可逆）

- **为什么最急**：小游戏备案提交前会**锁定名称与主体**，通过后**不能改名**（官方规定）。
  名字一旦报上去，改就要走变更登记，非常麻烦。
- **怎么定**：建议格式「品牌词 + 类型」，例如 **纯净玩**、**纯净玩棋类合集**、**闲棋**。
- **个人命名红线**（2026 从严）：
  - ❌ 不得含企业/单位名义（"XX公司""XX集团"）
  - ❌ 不得涉及前置审批领域（新闻、金融、医疗、教育培训、网约车……）
  - ❌ 不得用宽泛领域词（"商城""商贸"）
  - ❌ 不得与已有商标近似
- **动作**：把候选名字写下来，去微信公众平台注册时先占位。

### ② 准备注册用的材料（半小时的事）

| 材料 | 说明 |
|---|---|
| 身份证 | 正反面拍照/扫描，**四角完整、无反光** |
| 本人微信号 | 需要实名认证过的微信号做管理员 |
| 手机号 | 接收验证码（与微信号一致最省事） |
| **多个邮箱** | ⚠️ **一个邮箱只能注册一个小游戏**。你计划发多个，现在就多注册几个免费邮箱（QQ/163 都行），每个记下来对应哪个游戏 |
| 本人银行卡 | 以后开通广告分成要用（现在不做广告可先不管） |

### ③ 注册小游戏账号（当天可完成）

1. 打开 <https://mp.weixin.qq.com> → 右上角「立即注册」→ 选「**小程序**」
2. 填邮箱（专用的那个）→ 收激活邮件 → 点链接
3. 主体类型选「**个人**」（⚠️ 不可逆：个人主体不能开内购、不能微信认证）
4. 填身份证信息 + 管理员微信扫码验证
5. 登录后台，完善「小程序信息」：名称、头像、简介、**服务类目选「游戏」**
6. 在「设置 → 基本设置」记下 **AppID**（`wx` 开头）

**完成后把 AppID 告诉我**，我可以用命令行工具做自动化验证（打开项目、出预览二维码、截图核对）。

### ④ 开始准备软著材料（不用等，先了解）

- 软著是**关键路径**：普通流程 **30–60 工作日**，是整条链里最慢的一环
- **但现在还不要提交**：代码还在增加（要加蜘蛛纸牌、斗地主、麻将等），
  软著材料里的**行数、版本号、页数必须与申请表完全一致**，提前提交后代码又变了会自相矛盾
- **现在能做的**：在中国版权保护中心 <https://register.ccopyright.com.cn/> 完成**实名认证**
  （个人要身份证 + 人脸），这样等材料一好就能立刻提交

## 二、等游戏开发完成后要做的事（我会准备好材料，你只管提交）

### ⑤ 生成并打印软著材料

我会用 `tools/make-copyright.mjs` 生成三份东西：

| 文件 | 用途 |
|---|---|
| `纯净玩…_源程序.html` | 浏览器打开 → Ctrl+P → 另存为 PDF → 打印（A4、纵向、单面、黑白） |
| `纯净玩…_源程序.txt` | 纯文本版备用 |
| `纯净玩…_源代码统计.txt` | **填申请表用**：总行数、页数、含哪些文件 |

**官方规格（务必核对）**：
- 源程序：提交**前、后各连续 30 页**（共 60 页）；不足 60 页则全部提交
- 源程序**每页不少于 50 行**，**最后一页必须是程序结束页**
- 文档（说明书）：**每页不少于 30 行**（有图除外）
- 页眉标注**软件名称 + 版本号**，右上角标注**页码**，且**与申请表完全一致**
- A4、纵向、单面、**黑白打印**

### ⑥ 提交软著申请

三样材料：
1. **申请表**：在线填写 → 打印（不得改格式）→ 自然人**签字**
2. **鉴别材料**：源程序 + 文档（上面的打印件）
3. **身份证明**：身份证正反面复印件

申请表关键字段：
- 软件全称：`纯净玩棋类益智游戏合集软件`（品牌 + 功能 + "软件"）
- 版本号：`V1.0`（**所有材料一致**）
- 开发方式：**单独开发**；权利取得：原始取得
- 开发完成日期：代码定稿日

### ⑦ 游戏自审自查报告

- 微信公众平台 → 小游戏后台 → 下载**官方模板**
- 打印后**本人签字按手印**，扫描上传
- 内容：游戏不含违规内容（色情/暴力/赌博/涉政）、不诱导分享等

### ⑧ 小游戏备案 + 小程序备案（ICP）

- 入口：微信公众平台 → 「设置 → 基本设置 → 小程序备案」
- **注意**：
  - 通讯地址要**精确到门牌号**
  - **应急联系人不能与本人同一手机号**
  - 部分地区要**手写签名按手印**的承诺书
  - 需**负责人现场拍摄照片**（平台操作时完成）
  - 工信部短信核验（**12381**）必须 **24 小时内**完成，逾期驳回
- 耗时：平台初审 1–2 天 + 主管部门 10–20 工作日；ICP 约 10–30 工作日

### ⑨ 上传版本 → 提审 → 发布

- 开发者工具右上角「**上传**」→ 后台「版本管理」→ 提交审核 → 通过后「发布」

## 三、时间线（建议照这个顺序推进）

```
今天        ① 定名字  ② 备材料  ③ 注册账号  ④ 软著实名认证
              ↓（与此同时，我把游戏做完）
本周        ⑤ 生成软著材料 → 打印 → ⑥ 提交软著
              ↓（软著审查 30–60 工作日，期间并行）
同时        ⑦ 游戏自审自查报告
软著到手后   ⑧ 小游戏备案 + ICP 备案
备案通过后   ⑨ 上传 → 提审 → 发布上线
上线后       暂不开广告（纯净玩定位）→ 累积到 500 独立用户再考虑流量主
```

**一句话**：**名字最急**（不可逆），**软著最慢**（30–60 工作日，要尽早启动），
其余都可以并行准备。

## 四、常见被拒 / 补正原因（提前避开）

| 现象 | 原因 |
|---|---|
| 软著被要求**补正** | 申请表填的行数与实际材料不符；页眉名称/版本号与申请表不一致；最后一页不是程序结尾 |
| 备案驳回 | 通讯地址不精确；应急联系人与本人同号；**短信核验超 24 小时** |
| 提审被拒 | 类目选错；功能与类目不符；含未报备的敏感内容 |
| 名称被拒 | 含企业名义 / 前置审批领域 / 宽泛词 / 与商标近似 |

### ⚠️ 关于 AI 辅助开发的提醒

公开资料提到软著审查**对"纯 AI 生成代码"趋于严格**（第三方说法，建议向代理机构核实）。
要**刻意保留人工创作证据**：
- 美术 / UI 设计稿、玩法与数值设计文档
- **细粒度的 git 提交历史**（最有力的开发过程证据，本项目一直在保持）
- 真机调试记录、版本迭代记录
