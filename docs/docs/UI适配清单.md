# UI 适配清单（现有游戏 → 统一青白主题）

> 背景：对局主题已统一为**青白渐变底 + 木质按钮**（集成层提供）。
> 本清单是代码审计结果，列出每个游戏还需要改什么。
> 规则依据见《游戏模块规范.md》第 10 节「边界约定」。

审计时间：2026-09-27

---

## 一、三类问题（按严重度）

### 问题 A：自带全屏背景，会盖住集成层的青白底  ★最严重

| 游戏 | 铺底处数 | 说明 |
|---|---|---|
| 中国象棋 | 5 | 自己的木框+底色，会覆盖青白渐变 |
| 国际象棋 | 7 | 同上 |
| 围棋 | 5 | 同上 |
| 俄罗斯方块 | 6 | 深色棋盘底 |
| 扫雷 | 6 | 需确认是否已用 theme 令牌跟随青白 |

**改法**：删掉游戏自己的 `fillRect(0, 0, w, h)` 全屏铺底（或改为 `theme.bgTop→bgBottom` 渐变）；
棋盘/牌桌等**局部**容器可以保留自己的材质，但不能铺满全屏。

### 问题 B：硬编码浅色文字（青白底上会"隐形"）

| 游戏 | 行号 | 残留写法 |
|---|---|---|
| 围棋 | L389、L402、L428 | `rgba(242,243,247,0.45)` / `0.40` / `0.28` |
| 扫雷 | L545、L622 | `rgba(242,243,247,0.38)` / `0.42` |
| 中国象棋 | L519 | `rgba(242,243,247,0.28)` |

`rgba(242,243,247,*)` 是**深色主题的浅字**，在青白底上等于看不见。

**改法**：一律换成主题令牌 —— 次要文字用 `theme.textMuted`，禁用态用 `theme.textMuted` 再降透明度，
正文用 `theme.textPrimary`。

> 说明：棋子/方块上的白色高光/描边（如 `rgba(255,255,255,0.3)`）**是合理的**，不用改 ——
> 它画在深色棋子上，不是画在背景上。

### 问题 C：按钮没走统一木质外观

**全部 9 个游戏** 的 `drawWoodButton` 使用次数都是 **0** —— 各自画按钮，风格不统一。

**改法**：底部操作按钮改为调用集成层导出的 `drawWoodButton(ctx, rect, label, opts)`：
- 主操作（重新开始 / 出牌 / 发牌）传 `primary: true`
- 次要操作传默认
- 不可用时传 `disabled: true`

## 三、修复时的验收标准（每个游戏都要过）

1. `node --check` 全部文件通过
2. `node src/games/<id>/test.mjs` 全过且退出码 0（**改 UI 不许弄坏逻辑测试**）
3. 截图核对：
   - 背景是青白渐变（不是深色、不是纯白）
   - 顶部 HUD 不与左上返回键、右上齿轮重叠
   - 底部按钮在 `insets.bottom + 16` 之上
   - 所有文字清晰可读（无"隐形字"）
   - 按钮风格与其他游戏一致（木质）
4. 结算：不自动重开，`outcome` 保持返回
