# 微信小游戏上架操作手册（个人主体）

> 2026-09 整理｜来源：中国版权保护中心登记指南、北京市政务服务网登记事项、微信官方文档
> ⚠️ 平台规则与登记要求会调整，**提交前以官网实时要求为准**。

---

## 一、总览：一共要走 7 步

| 步骤 | 事项 | 去哪办 | 耗时 | 花钱吗 |
|---|---|---|---|---|
| ① | 注册小游戏账号 | mp.weixin.qq.com | 当天 | 免费 |
| ② | **软著登记** | 中国版权保护中心 | **30–60 工作日** | 官方免费；加急找代理 1000–1500 元 |
| ③ | 游戏自审自查报告 | 微信后台（模板） | 1 天 | 免费 |
| ④ | 小游戏备案 | 微信后台 | 平台 1–2 天 + 主管部门 10–20 工作日 | 免费 |
| ⑤ | 小程序备案（ICP/工信） | 微信后台 | 10–30 工作日 | 免费 |
| ⑥ | 版本提审 → 发布 | 微信后台 | 1–3 天 | 免费 |
| ⑦ | 流量主 + 广告（可选，后置） | 微信后台 | 满 500 独立用户后 | 免费 |

**关键路径是第 ② 步（软著）**，所以它必须**最先启动**——其余步骤都可以和它并行准备。

---

## 二、① 注册小游戏账号

1. 打开 <https://mp.weixin.qq.com> → 右上角「立即注册」→ 选「**小程序**」
2. 主体类型选「**个人**」（⚠️ 不可逆：个人主体**不能**开通内购/支付，也没有微信认证）
3. 填邮箱（**一个邮箱只能注册一个小游戏**，多产品请提前准备多个邮箱）、密码
4. 邮箱激活 → 选择主体类型「个人」→ 填身份证 + 管理员微信扫码验证
5. 完善「小程序信息」：
   - **名称**：个人命名有红线（见下），**备案前锁定后不可改名**
   - 头像、简介、服务类目（选「**游戏**」相关类目）
6. 在小程序后台 → 「设置 → 基本设置」里能看到 **AppID**（`wx` 开头）

**个人命名红线（2026 从严）**
- ❌ 企业/单位名义（"XX公司""XX集团"）
- ❌ 前置审批领域（新闻、金融、医疗、教育培训、网约车…）
- ❌ 宽泛领域词（"商城""商贸"）
- ❌ 与商标近似
- ✅ 建议：`品牌词 + 产品类型`，例如「纯净玩棋类合集」

## 三、② 软著登记（重点，材料已帮你生成）

### 3.1 在哪办

- 官网：中国版权保护中心 <http://www.ccopyright.com.cn/>
- 在线申请入口：<https://register.ccopyright.com.cn/>
- 必须先做**实名认证**（个人用身份证 + 人脸），否则无法提交

### 3.2 要提交的三样东西

| 材料 | 具体要求 |
|---|---|
| **① 计算机软件著作权登记申请表** | 在线填写后**打印**，不得改格式；自然人**签字**（与申请表姓名完全一致） |
| **② 软件鉴别材料**（源程序 + 文档） | 见下方规格 |
| **③ 身份证明** | 自然人身份证**正反面复印件** |

### 3.3 源程序的规格（最容易被打回的地方）

- 提交**前、后各连续 30 页**（共 60 页）；**不足 60 页的全部提交**
- **每页不少于 50 行**；**最后一页必须是程序的结束页**（别让最后一页是写到一半的代码）
- **页眉**标注：软件名称 + 版本号（**必须与申请表完全一致**）
- **右上角**标注页码
- A4 纸、纵向、单面、**黑白打印**
- 实操建议：删掉纯空行凑够密度；材料总行数要和申请表里填的"源程序行数"对得上，否则会被**要求补正**

### 3.4 文档（说明书）的规格

- 同样提交前后各连续 30 页（不足则全部）
- **每页不少于 30 行**（有图除外）
- 内容：软件功能、操作说明、界面说明、运行环境等
- 页眉同样标名称+版本号

### 3.5 申请表里的关键字段怎么填

| 字段 | 填法 |
|---|---|
| 软件全称 | 命名规范：**品牌 + 产品用途与功能 + "软件"**，例如 `纯净玩棋类益智游戏合集软件` |
| 简称 | 可留空（不能与全称相同） |
| 版本号 | `V1.0` 或 `1.0`（**所有材料必须一致**） |
| 开发完成日期 | 代码定稿的日期 |
| 发表状态 | 未发表（上线后再登记变更，或填首次发表日期） |
| 开发方式 | **单独开发**（自己独立完成） |
| 权利取得方式 | 原始取得 |

> 名称结尾提示：以「软件、系统、平台、插件、中间件」结尾可以申请；以「工具、计算、系列」结尾要慎用。

### 3.6 时间与费用

- **官方登记免费**（2017 年起取消登记费）
- 普通流程：**受理后 30–60 工作日**（各地登记中心初审 20 个工作日后上报中心，中心审查另计）
- 加急：通过代理办理，**3–30 工作日**，市场价约 1000–1500 元

### 3.7 我们已经准备好的材料

在 `F:\游戏\pureplay\docs\copyright\` 下：

| 文件 | 用途 |
|---|---|
| `纯净玩…_源程序.html` | **打印用**：浏览器打开 → Ctrl+P → 另存为 PDF（A4/纵向）→ 打印 |
| `纯净玩…_源程序.txt` | 纯文本版（含页眉/页码/换页符），需要纯文本时用 |
| `纯净玩…_源代码统计.txt` | 填申请表用：总行数、页数、包含哪些文件 |

生成命令（代码更新后重新生成）：
```bash
cd F:\游戏\pureplay
node tools/make-copyright.mjs "纯净玩棋类益智游戏合集软件" "V1.0"
```

> ⚠️ **代码还在增加**（还要加中国象棋、围棋、国际象棋、扫雷、俄罗斯方块）。
> **建议等所有游戏做完再生成最终版**——软著材料一旦提交，版本号与行数都要自洽。

## 四、③ 游戏自审自查报告

- 微信公众平台 → 小程序后台 → 「游戏」相关入口可下载**官方模板**
- 自然人手写/打印后**签字按手印**，扫描上传
- 内容：游戏不含违规内容（色情、暴力、赌博、涉政等）、不诱导分享等
- 与软著是两回事，**两个都要**

---

## 五、④ 小游戏备案

- 入口：微信公众平台 → 「设置 → 基本设置 → 小程序备案」，或首页的备案引导
- 平台初审 1–2 个工作日 → 报送主管部门 **10–20 个工作日**
- 备案提交前会**锁定名称与主体**，通过后不能改名/改主体
- 个人纯广告（无内购）走**情况二**的流程

---

## 六、⑤ 小程序备案（工信/ICP）

- 在微信后台按引导填写：主体信息、小程序信息、负责人信息
- **注意点**
  - 通讯地址要**精确到门牌号**
  - **应急联系人不能与本人同一手机号**
  - 部分地区要求**手写签名按手印**的承诺书（平台会生成）
  - 需**负责人现场拍摄照片**（在平台操作时完成）
- 流程：信息填写 → 平台初审 → **工信部短信核验（12381，24 小时内必须完成，逾期驳回）** → 省通信管理局审核（10–30 工作日）→ 下发备案号

---

## 七、⑥ 版本提审与发布

1. 微信开发者工具 → 右上角「**上传**」（填版本号 + 项目备注）
2. 小程序后台 → 「版本管理」→ 提交审核（选好类目、填功能页面）
3. 审核 1–3 天；通过后点「**发布**」
4. 发布前确认：备案号已下发、软著材料已上传、类目正确

---

## 八、⑦ 流量主与广告（你现在不做，留个记录）

- 门槛：**累计 500 个独立用户**访问
- 广告形式：激励视频（收益最高）、插屏、Banner、格子
- 2026 政策：30 天 90% 快速回收 / 90 天 85% 长线留存，双轨可选
- 你的定位是「纯净玩」——**先不开广告**，等留存验证过再考虑；代码里目前**一行广告都没有**

## 十、常见被拒/补正原因

| 现象 | 原因 |
|---|---|
| 软著被要求**补正** | 申请表填的行数与实际材料不符；页眉名称/版本号与申请表不一致；最后一页不是程序结尾 |
| 软著被拒 | 材料明显非自主开发（⚠️ 见下方提醒）；代码里含他人版权内容 |
| 备案驳回 | 通讯地址不精确；应急联系人与本人同号；**短信核验超过 24 小时** |
| 提审被拒 | 类目选错；功能与类目不符；含未报备的敏感内容 |

### ⚠️ 关于 AI 辅助开发的特别提醒

公开资料提到软著审查**对"纯 AI 生成代码"趋于严格**（第三方说法，建议向代理机构核实）。你的项目是 AI 深度参与开发的，因此要**刻意保留人工创作证据链**：
- 美术/UI 设计稿、玩法与数值设计文档
- **细粒度的 git 提交历史**（最有说服力的开发过程记录）
- 真机调试记录、版本迭代记录

不要把"一份 AI 对话记录生成的代码"作为唯一材料提交。
