# 纯净玩 · 棋类小游戏合集

一个**可在微信开发者工具里直接运行**的原生小游戏，定位是「**纯净玩**」——
**不做广告、只做游戏本身**，用一个大厅把多款棋类游戏装进**同一个 AppID**。

> 为什么这么做：个人主体最多只能注册 5 个小游戏，而"小程序跳转小游戏"**并不能绕过这个上限**
> （被跳转的小游戏仍要各自注册与备案）。唯一能把多个玩法装进一个名额的办法，
> 就是**一个小游戏内含多个玩法**。本项目的"大厅"就是为此设计的。

## 界面流程

```
纯净玩大厅（游戏列表）
   └─ 点「五子棋」
        └─ 选择模式（休闲版 / 专业版，上下两块）
             └─ 选择难度（简单 / 普通 / 困难 / 地狱 / 亚洲）
                  └─ 进入对局  ← 可随时「返回」取消，或「认输」回大厅
任意界面右上角齿轮 → 设置（背景音乐音量）
```

## 关于背景音乐

用 **Web Audio 程序化合成**（`src/audio/bgm.js`），没有音频文件：
- 音色：基频三角波 + 八度/十二度泛音 + 拨弦包络（快起音、指数衰减）+ 低通滤波 → 古筝/竖琴感
- 旋律：D 宫调五声音阶，约 62 BPM，长音与级进为主，循环播放（悠扬、平静）
- 好处：**主包零增长**（小游戏主包只有 4MB，一段真古筝曲通常 1–3MB）
- 设置里的滑块实时改音量（0 = 静音）；切后台自动停、回前台续播
- 想换成真人演奏的曲子：把 `bgm.js` 换成 `wx.createInnerAudioContext()` 加载音频文件即可，音量接口保持不变

## 怎么跑

**① 微信开发者工具**（真正的目标环境）
```
用「微信开发者工具」打开本目录（compileType 已设为 game）
```
> ⚠️ **AppID 必须换成你自己的**：`project.config.json` 里的 `appid` 字段。
> 新版开发者工具**已不支持 `touristappid`**（游客模式会被拒：`不存在此 AppID`）。
> 取值处：开发者工具 → 打开项目后右上角「详情 → 基本信息 → AppID」，或工具首页项目卡片。
> 想用「测试号」：在 [mp.weixin.qq.com](https://mp.weixin.qq.com) 申请测试号后填入。

**② 浏览器预览 UI**（不依赖微信环境，改样式时最快）
```
node tools/preview-server.mjs 8099
浏览器打开 http://127.0.0.1:8099/preview/
```
可加参数模拟实机安全区，验证「底部按钮是否被系统手势条遮挡」：
```
http://127.0.0.1:8099/preview/?inset=34&status=44
```

**③ 只测逻辑**（最快，零依赖）
```
node tools/test-core.mjs
```

## 怎么玩

**主界面**（青白渐变 + 木质卡片）
- 选**规则**：`休闲版`（无禁手，随意落子）/ `专业版`（连珠规则）
- 选**难度**：`简单 / 普通 / 困难 / 地狱 / 亚洲`
- 点「开始对弈」进入对局；对局中左上角圆形按钮可返回主界面

**专业版规则（连珠）**
- 黑棋禁手：**三三**（同时两个活三）、**四四**（同时两个四）、**长连**（六子及以上）
- 白棋无禁手；AI 执黑时也会主动避开禁手点
- 落子在禁手点会被拦截并弹出提示

**五种难度的差异**

| 难度 | 策略 |
|---|---|
| 简单 | 只看自己进攻、大量随机抽样，会漏防（也可能看漏你的杀招） |
| 普通 | 攻防兼顾（防守权重 0.9），会堵冲四 |
| 困难 | 增加一步前瞻，避开「我下完对手立刻活四」的坑 |
| 地狱 | 强制必堵优先 + 主动制造双威胁（双四 / 双三） |
| 亚洲 | 更宽前瞻 + 对手反击后的二次校验 + 禁手感知，几乎不失误 |

**操作**：点交叉点落子（黑先）；底部按钮为**重新开始 / 悔棋**（人机撤两手）/ **换边**。

## 设计要点

- **棋盘**：木色渐变 + 细木纹 + 内阴影 + 圆角投影，星位点五处。
- **棋子**：径向渐变球体 + 高光 + 投影，落子用 easeOutBack 弹出动画（140ms）。
- **信息层级**：顶部标题 + 执子/回合状态（带小棋子图标）+ 手数 + 战绩；底部按钮胶囊形，带按压反馈。
- **适配**：全部按逻辑像素绘制，物理像素由 dpr 缩放；布局函数根据屏幕尺寸实时计算，窄屏/长屏都不会挤压棋盘。

## 架构约定（与「荒潮拾荒者」一致）

1. **core 纯逻辑**：不引用任何平台 API，可在 Node 里直接跑测试（`tools/test-core.mjs` 覆盖棋盘、四向五连、悔棋、胜负锁定、候选点、AI 棋力、克隆隔离）。
2. **ui 纯绘制**：只接收 `ctx + layout + state + theme`，不持有状态，因此同一份渲染代码能同时服务小游戏与浏览器。
3. **平台层薄**：`game.js` 只做三件事——建上屏画布、转发触摸、驱动帧循环。

> 小游戏环境**没有 document / window**，所以这里不使用任何 DOM API；这也正是迁移「荒潮拾荒者」时必须先解决的问题。
